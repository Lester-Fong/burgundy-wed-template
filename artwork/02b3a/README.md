# 02B.3A fashion illustration proof

This folder preserves the two owner-approved original watercolor specimens. Both are used as source artwork for the default production Attire Guide, alongside six new originals documented in `../02b3b/README.md`. Both 1024 × 1536 PNGs have an alpha channel and use client-provided wedding-party colors.

- `gown-taupe-watercolor.png`: Taupe Brown `#A67C5E`.
- `suit-mocha-watercolor.png`: Deep Mocha `#4C3626`.

Technique: generated original watercolor-style fashion art with transparent backgrounds, then inspected at the intended mobile, tablet and desktop sizes. The owner-provided images informed the editorial quality target; no reference figure was copied or traced. The generation tool was the built-in imagegen tool.

Compared with the rejected inline SVG figures, these specimens have a smaller head-to-body proportion, more natural stance, draped gown layers, tailored jacket construction, and tonal cloth texture. The supplied inspiration has a softer grouped watercolor composition; these isolated studies are darker and more photographic in finish. They were approved as the starting style for the complete collection.

## Generation prompts

**Gown:** One adult woman in a relaxed three-quarter fashion pose and a flowing taupe-brown formal gown. Sculpted fitted bodice, draped asymmetrical neckline, layered semi-sheer skirt, realistic folds, watercolor shadows and delicate highlights. Minimal serene facial details. Fine pencil and ink accents. Full figure on a transparent background; no other figures, text, scenery, or flat cartoon shapes.

**Suit:** One adult man in a relaxed three-quarter pose with a tailored deep mocha formal suit. Structured shoulders, narrow waist, defined lapels, seams, pocket square, cloth creases, restrained highlights and refined shoes. Minimal facial detail. Fine pencil and watercolor accents. Full figure on a transparent background; no other figures, text, scenery, or flat cartoon shapes.

## Recoloring assessment

These raster proofs contain skin, hair, cloth, highlights and painterly pigment in one RGBA image. Recoloring the whole image with CSS would alter skin and shading. For later client-specific color variants, either commission/export layered garment masks from the chosen art source or regenerate and approve one asset per palette. The typed `OutfitColors` values remain in wedding content; the SVG prototype is retired from live rendering.

The current production set uses individually generated color variants awaiting owner review. A future multi-client editor can revisit layered garment masks if it needs dynamic recoloring.

# Intro floral artwork

- `intro-florals-source.png` was generated for this project with the built-in imagegen tool. It is an original transparent arrangement of burgundy roses, ivory orchids, buds, and antique gold foliage. No image from the inspiration website was used.
- `../../public/images/template/intro-florals.webp` is the 960 × 640 production derivative. Run `node scripts/prepare-intro-art.mjs` from the project root to recreate it.
- Prompt direction: “Original premium wedding botanical cutout: a low open wreath of dark wine roses, creamy orchids, petite buds, and sparse antique gold leaves; the center stays open for a separate envelope. Natural dimensional detail, transparent background, no envelope, logo, text, frame, or watermark.”
- The browser renders two clipped halves of the same WebP so left and right flowers can bloom at slightly different times without downloading duplicate artwork.
